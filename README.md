# Collège NDC - Sciences Physiques

Petit site statique HTML/CSS/JavaScript destiné à héberger des QCM de sciences physiques.

## Mise en ligne sur GitHub Pages

1. Créer un nouveau dépôt GitHub, par exemple `college-ndc-sciences-physiques`.
2. Ajouter tous les fichiers contenus dans ce dossier.
3. Dans GitHub, ouvrir `Settings`.
4. Aller dans `Pages`.
5. Dans `Build and deployment`, choisir `Deploy from a branch`.
6. Sélectionner la branche `main` et le dossier `/root`.
7. Enregistrer.

GitHub fournira ensuite l'adresse du site.

## Ajouter un QCM

Le premier exemple se trouve dans :
- `qcm/6e/matiere.html`
- `js/quiz-6e-matiere.js`

Pour créer un nouveau QCM, dupliquer ces fichiers puis modifier les questions dans le fichier JavaScript.
